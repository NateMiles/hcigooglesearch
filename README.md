# Vibe Search: Final Prototype

Clickable medium-fidelity prototype for an HCI individual project: searching Google Maps by vibe and features (for example, "a cozy coffee shop with free books and good food"). It combines plain-language search with removable vibe chips and review evidence for each quality.

Live: https://natemiles.github.io/hcigooglesearch/

Places, reviews and reviewers are made up. The prototype was built with AI assistance from the author's designs and evaluation results.
